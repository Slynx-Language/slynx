# Generics Inference

Generics inference at the moment is not a thing, this is mainly due to me focusing on which I think is important, which is to make the components and styles work and so compile down to the browser properly, but keeping 
it useful enough to make it compile down to desktop as well. 
The main thing then is that generics at the moment are not inferred, they are explicitly specified, so the compiler does not know what type to infer for a generic parameter based on the given value.
This is idealized to be a thing on the future, but not now.
